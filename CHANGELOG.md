## 0.3.0

* Added Push Notification authentication flow (Push setup, approval, and verification with number matching).
* Added in-app notification banner widget (`OneAuthNotificationBanner`).
* Enhanced PIN verification and secure ID manager.
* Updated Firebase messaging and environment configurations.
* General performance optimizations and SDK improvements.

## 0.2.0

* Added TOTP authentication flow and responsive TOTP PIN input widget.
* Added hardware-backed Certificate Signing Request (CSR) and attestation manager (`OneAuthCsrManager`).
* Improved error handling across authentication flows and HTTP requests.
* Code refactoring and static analysis improvements.

## 0.1.0

* Initial release of OneAuth SDK.
* Multi-factor authentication (Biometrics, PIN, TOTP, Push).
* Automated client handshake and pre-authenticated Dio networking.
* Obfuscated environment config and secure storage support.
